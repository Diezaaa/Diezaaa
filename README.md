## Projects
### Done Mate
Done Mate is my flagship project: an offline-first Android task-management app. Users can create tasks that include images, due dates, reminders, and images. The user can take a photo for a task on a custom built camera screen that includes a preview and camera control settings. Additionally, users can track their progress. The app includes an inspiration screen which shows an endless scrollable feed (list) of motivational quotes to empower the user to test his limits. The app enables users to create account by using e-mail or linking their Google account. The user can choose between light or dark theme in the app's settings.

For a complete overview and code of the project, [click here to visit the project's page (project's repository)](https://github.com/Diezaaa/done-mate).
