## Projects
### Done Mate
I built Done Mate, an offline-first Android task-management app using Kotlin and Jetpack Compose.
- Implemented task management with images, due dates, and reminders, supporting offline access and syncing across devices using Room and Firebase Firestore.
- Organized the app into UI, domain, and data layers, with repositories for data access, use cases shared across ViewModels, and Hilt for dependency injection.
- Built an endless motivational quote feed supporting offline viewing and syncing liked quotes across devices with Paging 3, Retrofit, and Room.
- Added email/password and Google sign-in, account linking, password resets, email verification, and account updates using Firebase Authentication.
- Created a custom camera screen with a preview and camera controls, using CameraX to access camera capabilities and Firebase Storage to store task photos remotely.
- Added light and dark themes.

For a complete overview and code of the project, [click here to visit the project's page (project's repository)](https://github.com/Diezaaa/done-mate).
